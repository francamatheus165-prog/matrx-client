# Matrix Client

Browser Block Game Emulator with Toggleable Matrix Mods

## 🚀 Features

- 🎮 Electron-based game client
- 🔧 Customizable mods and settings
- 🎨 Theme support
- 🔄 Auto-update system
- 💬 Discord RPC integration

## 📦 Installation

### Download
Download the latest `.exe` from [Releases](../../releases)

### Build from source
```bash
git clone https://github.com/francamatheus165-prog/matrx-client.git
cd matrx-client
npm install
npm start
